Every project should answer seven questions.

This is now documented in a copy-ready snippet file included in the ZIP.

01

Problem

What need or difficulty did the project address?

02–04

Goal, tools and process

State what success meant, which technologies were used and how the team worked.

05–07

Result, failure and next step

Show evidence, explain what did not work and define the next improvement.
