DEVELOPMENT LOG · V1–V5

Five versions did not improve in a straight line.

Version 1 is assessed from the actual source files. Version 2 was mainly an audience and content strategy. Versions 3–5 produced new prototypes. This page records what each stage changed in the output, what survived, and what had to be reversed.

VERSION-BY-VERSION

What each version actually contributed.

A fuller plain-text analysis is included as DEVELOPMENT_ANALYSIS_V1-V5.txt.

Version 1 — real code and real evidence

The original source created a working bilingual static site with a photographic hero, members, popups, events, news and a 404 page. Its greatest value was not visual polish but the real people, event files and media that later versions could preserve.

THIS MADE IT WORSE — Version 1’s popup complexity

The elaborate member popup system exposed public social handles and added a large amount of inline code while doing little to help visitors understand classes or projects. The final people page is simpler, removes social handles and adds a consent requirement.

Version 2 — the right audience question

Version 2 reframed the site for prospective Pre-University students and proposed clearer CTAs, navigation and content hierarchy. Those ideas eventually became the applicant homepage, Pre-U Life page and Preparation Guide.

THIS DIDN’T HELP THE OUTPUT YET — Version 2 stopped at strategy

The audience notes were useful, but the actual files, one-page limitations, branding risk and broken news popup remained unchanged. A better prompt did not automatically create a better website.

THIS MADE IT WORSE — Version 3 branding

Version 3’s modern SJTU-red visual system and “交” mark looked polished but increased the risk of appearing officially affiliated. The final output removes the mark, official logo files and official-style copyright language.

Version 4 — the identity correction

The original code-bracket logo, independent name and visible disclaimer solved a concrete identity problem. These changes survived into the final output, although Version 4 still remained a one-page prototype.

THIS DIDN’T HELP — Version 5 homepage scope

Adding Chinese preparation, applications and AI news was useful in principle, but placing everything on the homepage weakened the coding story and still did not document real club life. The final version separates these topics into dedicated pages.

THIS DIDN’T HELP — the old news popup

The popup opened but never fetched or displayed the linked article; it only showed a loading message. The final news page uses direct source links.

Montserrat alone was not enough

Montserrat improved Latin typography but did not provide a professional Chinese type system. The final site pairs it with Noto Sans SC.

What changed in the files.
